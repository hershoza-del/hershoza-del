# Hi, I'm Hersh Oza 👋

I’m an Economics graduate, cum laude, from Rutgers University building practical experience in data analysis through independent projects. I use Python, SQL, Excel, R, and Tableau to investigate questions about public health, public spending, consumer behavior, or anything that I find fascinating!

My projects focus on cleaning data, checking results, identifying patterns, and communicating findings clearly.

## My approach

I typically use **Python (pandas, matplotlib)** to clean and reshape datasets, **SQL** and **Excel** to query and cross-check results, **R** for statistical analysis and visualization, and **Tableau (Public)** for additional interactive dashboards. The methods and tools vary depending on the question and dataset.

## How this evolved

My early projects helped me learn the basics of Python and SQL. As I’ve progressed, I’ve become more deliberate about choosing tools, validating findings, and documenting my analysis. Each repository reflects what I knew at the time and what I learned along the way.
